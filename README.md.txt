Dicee - DOM Challenge 🎲

A simple two-player dice game built with HTML, CSS, and JavaScript as part of the Angela Yu Web Development course.

Features

Generates random dice rolls for two players.

Updates dice images dynamically using JavaScript.

Determines the winner or displays a draw.

Manipulates HTML elements using the DOM.

Technologies

HTML5

CSS3

JavaScript

How to Run

Clone or download this repository.

Open dicee.html in your browser.

Refresh the page to roll the dice again.

What I Learned

DOM manipulation

JavaScript functions and conditionals

Generating random numbers with Math.random()

Updating HTML attributes with setAttribute()

Changing text with textContent
